# Changelog

## 0.5.1-community.2

- Bundle an optional authenticated, read-only CPA Limits sidecar with a pixel-terminal interface, synthetic demo mode, reset-card expiry and configurable display estimate/timezone.
- Persistent HTTPS sessions use signed, password-bound cookies. All business listeners require authentication; only a minimal liveness endpoint is anonymous.
- Optional official-cycle synchronization is disabled by default and applies to all plugin keys when enabled. Preserve confirmed values on query failure, expired data, rollback or account mismatch.
- Retain CPA-filtered scheduler candidates with historical error status; still reject disabled, banned, revoked and unavailable candidates.
- Escape attribute quotes in monitor key labels. Exclude account references, credential previews and cycle history from monitor snapshots.
- Build with Go 1.27.2 following the standard-library vulnerability audit; Node 24 frontend retains its exact lockfile.
- Include isolated CPA integration tests and synthetic browser screenshots. See VALIDATION.md for the dated checks and untested scenarios.

## 0.5.1-community.1

Based on upstream v0.5.1 under its original MIT license.

- Weekly usage is the default on key cards and usage details.
- Cards show usage, remaining budget and progress, with inline weekly-limit editing.
- Plugin navigation sits immediately beside the title.
- Management API can adopt a confirmed official cycle for all plugin keys. First adoption preserves usage; subsequent cycles archive earlier usage and replay post-boundary events. A trusted external synchronizer is required.
- Short user-supplied secrets are fully masked in previews; medium-length secrets expose fewer characters.
- Automatic saved-key reuse requires a readable same-origin parent and a same-origin API base without embedded credentials, query parameters or fragments.
- Explicit API URLs also reject embedded credentials and URL parameters. Failed login clears the in-memory session.
- Credential verification and public-price requests do not follow redirects or send referrers/cookies.
- Management HTML prevents cross-origin framing and MIME sniffing, disables caching and referrers.
- Frontend dependencies use the official npm registry and a refreshed exact lockfile. Single-file output is generated by a local build hook rather than the removed single-file dependency.
- CI has read-only repository permissions, pins official actions by commit and builds binary artifacts only on manual dispatch. No automatic publishing job is included.

This source edition has not been deployed to any running CPA instance. No production state or credentials are shipped.
